# UI_test

UI-прочес парка: разведки и трей-каркас — всё, что затрагивает
меню-бар/окна, но не является финальной утилитой. Пять ступеней
одного рецепта «как собрать тулзу для трею», от окна до боевых
фич, подмены живыми машинами и встречные уроки ширин/счётчиков.

## Почему `_test` (уровень зрелости)

UI-слой держится НЕ на одном фундаменте, а на двух развилках сразу:

- **железо**: телеметрия берётся с линейки PMU / SMU / SMC
  (G3/G4/G5/intel) — счётчики у классов разные вплоть до интерфейсов;
- **UI-API**: рендер обязан жить на 10.2–10.5 — NSStatusItem,
  objc-ABI (objc1 против дефолт-ABI), IOKit-клиенты и ширино-поведение
  пункта гуляют от версии к версии.

Каждая клетка этой матрицы (класс железа × версия OS X) должна быть
подтверждена живым запуском, прежде чем рецепт считается рабочим.
Подтверждённые клетки перечислены ниже в ступенях; всё остальное —
открытые клетки. Поэтому слоевое имя честное: **UI_test** — подтверждено
часть клеток, не вся матрица. Финальные тулзы в корне репо — это
клетки, доведённые до статуса «тавление факт».

## Состав

Разведки:

- `carbon-probe/` — окно с кнопкой, программный Carbon UI (Panther,
  кросс-PPC) — принцип «можно ли GUI крестом»: факт-запуск
- `tray-probe/` — два NSStatusItem без окна, objc1 — принцип
  «трей доступен»: факт-запуск

Боевые ступени (аргументы живых машин):

- `traycpu/` — CPU% via host_statistics (Panther 10.3.9, кросс-PPC)
- `diskgauge/` — W/R MB/s via IOKit IOBlockStorageDriver + dgprobe
  (Panther 10.3.9, кросс-PPC)
- `tempgauge/` — температуры via AppleSMC юзер-клиент + tmpprobe
  (leopard 10.5, натив) — единственная подтверждённая SMC-клетка;
  PMU-клетки (G3/G4) и SMU-клетки (G5) пока пусты

Общие уроки (полные в ридмих): поправка %03d-полей против «пляски»
цифр, ширина пункта = мера 13-пт гарнитуры + запас, бандл + `open`
как единственный ssh-путь запуска.
