# batinfo

Консольный статус батареи для PowerPC Mac (10.4/10.5). Только публичный
IOKit реестр. Автономная, чистый C.

## Пути данных (auto-detect)

- **PMU-эра (G3/G4 ноутбуки):** записи с `IOBatteryInfo` (nub `battery`
  под Mac-IO). Поля как публикует ApplePMU: Voltage (мВ), Current
  (мА·ч остаток), Capacity (мА·ч текущая полная), Amperage (мА),
  Cycle Count, Flags, AbsoluteMaxCapacity (мА·ч проектная).
- **Smart-battery стиль (более новые стеки):** записи с `MaxCapacity`
  + `Voltage` (ключи AppleSmartBattery) — заложено под будущие машины.
- Также выводит `IOHWSensor` узлы с location ~BATTERY (температура,
  voltage/current) — с тем же масштабом 16.16, что в fanmon.

## Происходные производные значения (вывод помечен derived)

- Remaining % = Current/Capacity (остаток от текущей полной ёмкости);
- Health % = Capacity/AbsoluteMaxCapacity (потери ёмкости от проектной);
- Подсчёт серий ячеек (3S/4S) и ~V на ячейку — **эвристика**, не факт из
  железа: работать только при остатке >50 % (при малом заряде диапазоны
  3S и 4S перекрываются).

Не выводится (в 10.4 PMU-стеке в реестре отсутствует): серийник, дата
производства, по-ячеечные напряжения (живут в SBS-регистрах батареи,
доступ — полуприватный SMBus-путь, вне текущих принципов).

## Запуск

```
./batinfo          # разовый вывод
./batinfo -w 2     # режим наблюдения, обновление каждые 2 с
```

Watch-режим рисуется без моргания: после 1-й рамки экран никогда не
очищается — кадр сначала целиком собирается в памяти (проход по реестру
долгий, очистка до него давала бы пустой экран), затем перерисовывается
поверх старого одним быстрым выводом (cursor-home, `\033[K` на строку,
`\033[J` ниже кадра). Выход — Ctrl-C. При отсутствии батареи (десктоп) —
честный отказ exit 1.

## Сборка

- **Канон пересборки** (решение 22.10.2026, как у pimem/diskbench): кросс-сборка
  на **intel-leopard** (`i686-apple-darwin9-gcc-4.0.1`, build 5493); нативная
  сборка на PPC-машине парка остаётся валидной.
- Три слоя G3-safe в Makefile (флаги одинаковы на обоих хостах):
  `-arch ppc -mcpu=G3 -Wl,-force_cpusubtype_ALL -mmacosx-version-min=10.3` +
  `CFLAGS -std=gnu99 -O2 -Wall`, линкер с
  `-framework CoreFoundation -framework IOKit`. Аудит после сборки:
  `otool -hv` → **PPC ALL**; `otool -tv | grep -icE 'v(a|m)[a-z]+'` → **0**.

```sh
# канон: кросс на intel-leopard (флаги уже в Makefile)
ssh intel-leopard
cd ~/Projects/batinfo
make clean && make        # затем аудит otool и слияние артефакта в гит (§3 скилла ppc-build)
# нативно (валидно): ssh <ppc-машина> — те же флаги из Makefile
```
