# tray-probe

Разведка №2: **вывод в «трей» (меню-бар) без главного окна** — можно ли
собрать такое для Mac OS X 10.3.9 (Panther) крестом с intel-leopard.
Ответ (24.10.2026): **ДА**, и objc-слой тоже работает.

## Что это

Приложение БЕЗ главного окна. Два пункта статуса справа в меню-баре:

```
[ 20с ]  [ 2000об ]        (воображаемые показания: температура и обороты вентилятора)
```

Клик в любой пункт гасит приложение (`setTarget`/`setAction`, без popup-меню).

## Результат разведки (живая машина PowerMac3,1 Panther 10.3.9)

- Пункты **отрендерились, шрифт немного хромает** — отнесено на счёт самой
  ОС/шрифта Пантеры, не тулчейна (верстка UTF-8 → CFString честная; можно
  позже попробовать фиксированную ширину в пункте или Arial-стиль, если
  захочется причесать)
- Клик → **корректный выход**, процесс чисто гаснет в `ps`
- Аудит бинаря: **PPC ALL**, VA=0, md5 `26f1f957561eb81f3ba466672e5674e0`

## Рецепт

Сборка (кросс на intel-leopard) — канон парка + objc:

```sh
gcc -arch ppc -mcpu=G3 -Wl,-force_cpusubtype_ALL \
    -mmacosx-version-min=10.3 -std=gnu99 -O1 -Wall \
    -fobjc-abi-version=1 \
    -x objective-c tray.m -o tray \
    -framework Foundation -framework AppKit
```

- **`-fobjc-abi-version=1`** — главный ключ всей вылазки: принудительно
  легаси (objc1) раскладка классов. Panther-runtime переваривает только её.
  Проверка после сборки: `otool -ov <bin>` должен декодировать класс в
  классической форме (`name 0x… ProbeTarget` + `method_imp …`).
- API — ранние AppKit: `NSStatusBar`/`NSStatusItem`, `setTitle:`,
  `setTarget:`/`setAction:`, `stringWithUTF8String` — всё с 10.0.
- ObjC-код — только objc1-конструкции: один подкласс NSObject, простые
  методы, **никаких properties/blocks**.
- **Кириллица**: `stringWithUTF8String` над UTF-8 строкой сорса — без
  октальных эскейпов (в C октал не умеет >3 цифр — ловушка, была снята во
  время сборки).

## Запуск по ssh — тот же протокол, что у carbon-probe

Минимальный бандл `TrayProbe.app` (Info.plist + MacOS/tray), `tar` несжатый
(на чистой Пантере нет gzip), `scp -O`, `open ~/TrayProbe.app` — ONLY launch
path: там LaunchServices поднимет процесс в консольной сессии (виден
`-psn_…` в `ps`). Выход: клик в пункт статуса.

## Выводы по парку (сумма двух разведок)

1. Кросс-сборка GUI на PPC-Пантеру с intel-хоста — **факт**:
   `carbon-probe` (окно) + `tray-probe` (трей, objc).
2. objc1 кросс-ABI работает — парк-инструменты могут использовать
   и Carbon, и лёгкий AppKit (статусные пункты, окна) — при дисциплине
   API ≤ 10.2 и `-fobjc-abi-version=1`.
3. Канон «что умеем» расширен: окно/кнопки/текст + меню-бар пункты.
   Кандидаты применения: трей-монитор фан/темпов (по духу fanmon),
   статус-статистика бенчей, просмотрщик hwshot.

## Как собрать ещё раз

```sh
# intel-leopard: слить папку, там make
make          # соберёт tray + TrayProbe.app
# или нативно на PPC-машине (Panther/Tiger с gcc): тот же make
# (флаги включают -arch ppc, родной хост соберёт)
```
